# ⚠️ چرا `/newapp` کار نکرد و راه‌حل قطعی

> **وضعیت فعلی (بررسی‌شده از API تلگرام):**
> ```
> @AILanguageEducationbot      → has_main_web_app: false ❌
> @LanguageEducationAdmin_bot  → has_main_web_app: false ❌
> ```
> یعنی هیچ‌کدام از دو ربات مینی‌اپ ثبت‌شده ندارند.

---

## 🔎 علت دقیق پیام خطا

صفحه تشخیص (که همین حالا اجرا کردم) این را نشان می‌دهد:

```
✅ SDK تلگرام لود شد          version=6.0
❌ initData خالی است          ← علت اصلی
✅ اتصال به سرور              200 در 299ms
✅ CORS preflight             HTTP 204
❌ احراز هویت                 HTTP 400 initData is required
```

**نکته کلیدی:** `platform=unknown`

این یعنی تلگرام اپ را به‌عنوان یک **وب‌ویو معمولی** باز کرده، نه Mini App واقعی.
در وب‌ویو معمولی، تلگرام **هیچ امضایی (`initData`) نمی‌فرستد** — پس سرور
نتواند هویت را تأیید کند.

**پس مشکل اینترنت شما نیست.** سرور، شبکه و CORS همه سالمند.

---

## ✅ راه‌حل — با دقت این مراحل را انجام دهید

اشتباه رایج: `/newapp` یک گفت‌وگوی **مرحله‌به‌مرحله** است. اگر یک مرحله را
رد کنید یا URL را بدون `https://` وارد کنید، ثبت ناقص می‌ماند.

### مرحله ۱ — باز کردن BotFather

در تلگرام، **[این لینک](https://t.me/BotFather)** را باز کنید و روی **Start** بزنید.

### مرحله ۲ — زدن دستور `/newapp`

دقیقاً این را تایپ و ارسال کنید:

```
/newapp
```

> اگر BotFather گفت `You have no bots`, یعنی از حساب اشتباهی وارد شده‌اید.

### مرحله ۳ — انتخاب ربات

BotFather لیست ربات‌های شما را نشان می‌دهد. **`@AILanguageEducationbot`**
را انتخاب کنید (روی نامش بزنید یا شماره‌اش را بفرستید).

### مرحله ۴ — عنوان (Title)

یک اسم کوتاه بفرستید، مثلاً:

```
آموزش زبان
```

### مرحله ۵ — توضیح (Description)

مثلاً:

```
معلم هوشمند زبان
```

### مرحله ۶ — عکس (Photo)

BotFather یک عکس می‌خواهد. می‌توانید فعلاً `/empty` بفرستید تا رد شود.
(بعداً می‌توانید از `/myapps` → Edit App → Edit Photo اضافه کنید.)

### مرحله ۷ — ⚠️ آدرس وب (Web App URL) — مهم‌ترین مرحله

این را **دقیقاً** و با `https://` بفرستید:

```
https://kpanah-lang.pages.dev
```

### مرحله ۸ — نام کوتاه (Short Name)

یک اسم کوچک انگلیسی، فقط حروف و عدد (بدون فاصله). مثلاً:

```
kpanahlang
```

> این همان چیزی است که در لینک `t.me/AILanguageEducationbot/kpanahlang`
> استفاده می‌شود.

### مرحله ۹ — تأیید

BotFather باید بگوید:

```
Success! The Mini App was added.
```

## 🔍 راه‌های باز کردن اپ پس از ثبت

پس از ثبت، **فقط** از این راه‌ها باز کنید:

### راه ۱ (مطمئن‌ترین) — دکمه منو در چت

1. در تلگرام، چت با `@AILanguageEducationbot` را باز کنید
2. کنار کادر پیام، یک **دکمه آبی/منو** (☰ یا آیکون اپ) ظاهر می‌شود
3. روی آن بزنید

### راه ۲ — لینک مستقیم

```
https://t.me/AILanguageEducationbot/kpanahlang
```

### راه ۳ — دستور `/start`

```
/start
```

سپس روی دکمه «🎓 باز کردن اپلیکیشن» بزنید.

### ❌ هرگز این کار را نکنید

به‌جای موارد بالا، آدرس `https://kpanah-lang.pages.dev` را **مستقیم در
مرورگر یا داخل چت** باز نکنید — بدون امضای تلگرام کار نمی‌کند.

## 🧪 تأیید موفقیت

پس از ثبت، من می‌توانم فوراً بررسی کنم. اگر خواستید، بگویید «چک کن».

معیار موفقیت این است که `getMe` برگرداند:

```json
"has_main_web_app": true
```

و در صفحه تشخیص ببینید:

```
✅ initData دریافت شد     طول=۲۳۴
✅ احراز هویت موفق
```

## 🆘 اگر `/newapp` گفت «این آدرس قبلاً استفاده شده»

این یعنی قبلاً ثبت شده اما برای **ربات دیگری**. راه‌حل:

1. `/myapps` را در BotFather بزنید
2. ببینید `kpanah-lang.pages.dev` روی کدام ربات است
3. یا آن را از ربات اشتباه حذف کنید (`/deleteapp`)، یا یک آدرس متفاوت بسازید

---

## 🆘 اگر BotFather اصلاً `/newapp` را نمی‌شناسد

نسخه تلگرام شما قدیمی است. از **Telegram Desktop** یا **نسخه وب**
([web.telegram.org](https://web.telegram.org)) استفاده کنید.

## 📱 راه موقت تا زمان ثبت (اختیاری)

اگر می‌خواهید همین حالا UI را ببینید (بدون اطلاعات واقعی):
یک نسخه دمو با داده ساختگی لازم است که در حال حاضر فعال نیست.

**پیشنهاد:** چون سرور و دیتابیس کامل آماده‌اند، فقط مرحله `/newapp`
باقی مانده — و آن ۲ دقیقه بیشتر وقت نمی‌گیرد.
