# سیاست نگهداری داده و حریم خصوصی

> این سند «وضعیت واقعی کد» است، نه یک سیاست آرمانی. هر بند با محل پیاده‌سازی مشخص شده.

## چه داده‌ای ذخیره می‌شود

| داده | جدول | هدف | نگهداری فعلی |
|---|---|---|---|
| هویت تلگرام (id، نام، username، عکس) | `users` | احراز هویت و نمایش پروفایل | تا حذف حساب |
| هدف/سطح/زبان/منطقهٔ زمانی | `users` | شخصی‌سازی مسیر | تا حذف حساب |
| ترجیحات (دقایق روزانه، یادآور، گویش) | `app_settings` کلید `user:<id>:prefs` | تنظیمات | تا حذف حساب |
| نقشهٔ یادگیری + تصمیم‌ها + نقض‌ها | `app_settings` کلید `user:<id>:map` | «نقشهٔ ثابت» و ممیزی | تا حذف حساب |
| پیشرفت بخش‌ها | `app_settings` کلید `user:<id>:parts:*` | ادامهٔ درس | تا حذف حساب |
| پاسخ‌ها و رویدادها | `telemetry_events` | تصمیم تطبیقی و آمار | **بدون انقضای خودکار** |
| واژه‌ها و جعبه‌های لایتنر | `lexical_items` | مرور فاصله‌دار | تا حذف حساب |
| متن پاسخ آزاد | `telemetry_events.payload.answer` (۳۰۰ کاراکتر) | شاهد یادگیری | بدون انقضا |
| متن مکالمهٔ نقش‌آفرینی | `telemetry_events.payload.transcript` (۸ پیام × ۲۰۰ کاراکتر) | بازرسی بازخورد | بدون انقضا |
| فایل‌های صوتی | Backblaze B2 + `media_files` | کش TTS | مادام (کلید = هش متن، بدون دادهٔ کاربر) |

## نکات مهم

- **صوت، صدای کاربر نیست.** هیچ ضبط میکروفونی ذخیره نمی‌شود (STT نداریم). فایل‌های B2 فقط TTS تولیدشده از متن درس‌اند و به کاربر خاصی وصل نیستند.
- **کلیدهای سرویس** فقط در secrets ورکر هستند (`SUPABASE_SERVICE_ROLE_KEY`, `MEDIA_S3_*`, `JWT_SECRET`, `PROVIDER_ENCRYPTION_KEY`).
- **حذف حساب:** `handleDeleteAccount` داده‌های کاربر را پاک می‌کند؛ اما ردیف‌های `telemetry_events` با `lesson_id` باقی‌مانده ممکن است یتیم شوند. **اقدام لازم:** پاک‌سازی آبشاری پیش از حذف حساب.
- **انقضای تلمتری:** ✅ **پیاده‌سازی شد** در کرون ساعتی:
  - متن `payload.answer` و `payload.transcript` بعد از **۹۰ روز** حذف می‌شود
    (فقط `mode/verdict/score/errorType/objectiveId/stage/day` می‌ماند)
  - ردیف‌های قدیمی‌تر از **۲۴ ماه** کاملاً پاک می‌شوند
  - محدودیت: هر اجرا حداکثر ۲۰۰ ردیف را strip می‌کند (کنترل هزینهٔ کرون)

## پیشنهاد سیاست (تصمیم با مالک محصول)

| داده | پیشنهاد |
|---|---|
| `telemetry_events` (بدون متن) | ۲۴ ماه |
| `payload.answer` و `payload.transcript` | ۹۰ روز، سپس فقط verdict/score بماند |
| `content_cache` | ۹۰ روز (کرون فعلی فقط کهنه‌ها را می‌زداید) |
| فایل صوتی B2 | بدون انقضا (کلید هش، بی‌نام) |
